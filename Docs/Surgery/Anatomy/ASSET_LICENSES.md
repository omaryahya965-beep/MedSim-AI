## Evaluated and not used
| Candidate | Reason |
|---|---|
| NIH 3D *Female lower-limb bones* (3DPX-016666) | **CC BY-NC-SA** (non-commercial). Bones only, no soft tissue. |
| Sketchfab / Fab knee and implant models | Need an account to download; many are non-redistributable or have unclear licences. Not used. |
| CGTrader / TurboSquid / MakerWorld knee models | Paid or licences prohibit redistribution. No purchase without approval. |
| Unity Asset Store medical packs | Paid. No approval. |
| BodyParts3D directly | Same geometry as Z-Anatomy, but without ligaments, menisci or cartilage. Z-Anatomy was chosen so the soft tissue fits its bones. |
| Proprietary implant CAD (any manufacturer) | Not permitted. The implant shapes here are generic and original. |
| Wraith VR (Ghost Productions) | Used only as a visual and functional reference from its public store page. No assets, textures, models or code were extracted. |
